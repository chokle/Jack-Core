# How Jack Works — Pilot Tutorial

Target length: 2:15–2:45
Format: direct screen recording of the real Jack production UI, narrated plainly.

## 0:00–0:15 — What Jack is

**Screen:** Jack home / Living Memory overview.

**Voice:**
“Jack is your AI journeyman for the skilled trades. Use him when a real question, problem, uncertainty, or decision comes up at work. The goal isn’t to stump him or rack up questions — it’s to see whether he actually helps when you need him.”

## 0:15–0:50 — Ask Jack

**Screen:** Open Ask Jack. Ask a safe, non-sensitive example such as: `What should I check before running FCAW in a windy outdoor area?`

**Voice:**
“Ask Jack works like talking to an experienced person on the crew. Ask naturally and give him whatever job context matters. Jack can use his knowledge and sources to answer. If an answer looks wrong, incomplete, unclear, or you wouldn’t trust it on site, say so. That feedback is useful.”

**Screen:** Point out citations/source controls briefly.

## 0:50–1:20 — Living Memory

**Screen:** Open Living Memory. Tap a trade hub, then a child node, then open its detail/inspector.

**Voice:**
“Living Memory shows what Jack currently knows and how that knowledge connects. Tap a trade to open its branch, then tap individual concepts, procedures, hazards, tools, or other nodes to explore deeper. You can move around the graph yourself and ask Jack about whatever you’re looking at.”

## 1:20–1:40 — Library

**Screen:** Open Library and one safe sample record/video if available.

**Voice:**
“The Library contains the source material Jack has learned from. Use it when you want to inspect the original material, revisit a video, or follow a citation back to its source.”

## 1:40–2:00 — Interview

**Screen:** Open Interview Mode.

**Voice:**
“Interview Mode is how experienced workers can add field knowledge. Use it when there’s something Jack should know from real experience — a procedure, field tip, common mistake, site-specific lesson, or something the books don’t explain very well.”

## 2:00–2:20 — Navigation + context

**Screen:** Open sidebar/menu and move between two surfaces.

**Voice:**
“You can move between Jack’s tools from the menu. Jack is being built to understand where you are inside his own app, so you shouldn’t have to keep explaining what page or memory you’re looking at.”

## 2:20–2:40 — What we need from pilot users

**Screen:** Return to Living Memory or Ask Jack.

**Voice:**
“For this pilot, use Jack when real situations come up. At least one meaningful use a day is useful, but natural repeat use matters more than a high count. If Jack saves you time, helps you decide something, gets something wrong, or something in the app feels broken or confusing, tell us. That’s exactly what we’re testing.”

## Recording notes

- Record the current production UI only after the live path is confirmed stable.
- Use no confidential jobsite/project/customer information.
- Keep cursor/touch movement deliberate and slow enough to follow on a phone.
- Capture at 1080p where possible; frame important controls near the center because many pilot users will watch on mobile.
- Add captions from this script.
- Avoid edits that make features appear faster or more reliable than the live product.
- If a surface is not production-ready, do not feature it as working in the tutorial.
