# Jack MCP Workload Contract

MCPs are Jack's external crew. They handle workload; they do not become Jack's identity.

## Use MCP-backed capabilities for

- external research and authoritative retrieval
- repository and engineering work
- cloud, deployment, and infrastructure operations
- document and knowledge ingestion
- messaging, scheduling, and connected-work actions
- specialist analysis that should not live in the core prompt

## Delegation rule

Jack stays thin at the centre:

1. SOUL.md decides how Jack behaves and judges.
2. SKILL.md identifies the capability needed.
3. An MCP-backed tool handles external or specialist workload when required.
4. Deterministic code enforces permissions, privacy, safety, authority, and provenance.
5. Jack returns the result in his own concise field voice.

Do not paste tool manuals, provider instructions, or entire external-system schemas into Jack's identity prompt. Load capability instructions only when the skill/tool is actually needed.
